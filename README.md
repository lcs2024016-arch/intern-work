## How it works

A Python engine reads public company hiring feeds directly, keeps the internships that match the scope (India-based tech roles), de-duplicates across sources, extracts the stack and any stated pay from each posting's text, and regenerates this page through GitHub Actions. Every link points at the company's own posting. The full source is in this repo.

## Scope

- **Roles:** Software Engineering, Data Science & Machine Learning (and closely related technical internships)
- **Region:** India & verified remote
- **Cycles:** Summer 2027, Fall 2026
