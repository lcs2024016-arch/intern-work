## How this stays current

_Engine (last run): **5,425 companies** across **25 ATS platforms** · 100% fetch success · real posted dates on 87% of open roles · median detection lag 17.8h. One async pass every two hours, with retry/backoff, per-host rate limits and a circuit breaker that quarantines dead endpoints._

## How it works

A Python engine reads public company hiring feeds directly, keeps the internships that match the scope, de-duplicates across sources, records each role's published date once so it never shifts, extracts the stack and any stated pay from the posting's own text, and regenerates this page through GitHub Actions. Every link points at the company's own posting. The full source is in this repo.

Companies are found two ways: dataset mining for ATS tokens, and InternDoer's public feed used purely as a list of which employers are hiring in India. Either way the roles come from each employer's own careers system.
